# GigaDrive apps by plan (10 Gbps plans)

Copied from GigaRapid's "GigaDrive Supported Apps" page (saved October 2026).
**My plan: Gold G10.** I can install every app below except **Handbrake**
(needs Iridium G10 or higher).

How to read the table: GigaRapid lists the plans from smallest to largest:
Trial → Eco AF10 → Eco AF20 → Eco AF30 → Mini G10 → Mini G20 → Basic G10 →
Gold G10 → Platinum G10/G20/G30 → Iridium G10/G20/G30 → Osmium G10.
An app is available on its "lowest plan" and on every plan above it.
(The Trial plan can install every app.)

Apps that don't count toward my bandwidth quota (from my Bandwidth Status
page → Exempted Apps): **Default FTP Server, Simple Browser, Advanced
Browser, vsftpd.**
